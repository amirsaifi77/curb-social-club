Every state, at rest

Static renders of the nine states, in the phone's current scheme. Width never changes between states; only fill, stroke, label, and the 20pt icon slot do.

Timings

Exported as motion in packages/design-tokens/tokens.json so Figma, iOS, and web agree. Easing is cubic-bezier(0.2, 0, 0, 1) everywhere except the press, which is a spring on iOS (damping 20, stiffness 300, mass 0.6).
